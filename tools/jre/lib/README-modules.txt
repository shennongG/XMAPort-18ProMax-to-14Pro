The bundled jre/lib/modules (57 MB) is omitted from git to stay under the GitHub blob limit.
On first run, XMAPort uses the system Python; apktool only needs tools/jre/bin/java.exe.
If a step requires the full JRE runtime, install a JRE 17+ locally or restore modules
from the upstream XMAPort repo (https://github.com/NorthStarK-Lvy/XMAPort) tools/jre/lib/modules.
